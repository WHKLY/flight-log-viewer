# v0.1.2

- Fix the final open-ended mission version being treated as ending at zero. Playback switches to the second route at its start time and keeps 2D, 3D, HUD and the waypoint list consistent.
- Support both mission domain data and legacy mission-source JSON. Keep incomplete tlog routes out of automatic selection when a complete onboard route exists.
- Add Current/All route views and per-route visibility. Waypoint clicks identify both route and sequence, avoiding confusion when sequences repeat across routes.
- Preserve live panel nodes, scrolling and input focus during playback, and remove duplicate frame refreshes.
- Prevent narrow HUD canvas errors and separate mobile HUD/readout layout.
- Add a portable Python launcher, Bash wrapper and Windows command wrapper. Resolve project paths automatically, run all four data generators, stage successful builds, and retire stale mission domain files only after a new build succeeds.
- Add launcher and mission-playback regression checks. Keep local datasets and generated mission domains out of Git.

Python 3.11 or newer is required. Use `bash start.bash --dataset PATH` on Linux/Termux, `.\start.cmd --dataset PATH` on Windows, or invoke `start.py` with Python directly. Use `--skip-build` to view existing data.
